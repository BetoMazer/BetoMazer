Para onde vão os eleitores dos candidatos eliminados

Porcentagem dos eleitores de cada candidato (entre os que votarem em alguém no 2º turno) que vai para Flávio; o restante vai para Lula. Isso define a linha de base de cada município. Durante a apuração o modelo mede o quanto cada município apurado se afasta dessa base e aplica esse desvio aos não apurados — ou seja, a premissa pesa muito no início e quase nada depois de ~2–5% das seções.
