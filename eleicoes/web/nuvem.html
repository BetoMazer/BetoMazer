Controle da apuração

  1. No domingo, a partir das 16h30 (Brasília), o Claude fica de prontidão nesta sessão.
  2. Ao apertar Iniciar, ele começa a coletar os 5.757 municípios no site do TSE e atualiza este painel a cada ~90 s. A divulgação do TSE começa às 17h.
  3. Se ninguém apertar até 17h05, a coleta começa sozinha, para não perder o início.

Para onde vão os eleitores dos candidatos eliminados

Porcentagem dos eleitores de cada candidato (entre os que votarem em alguém no 2º turno) que vai para Flávio; o restante vai para Lula. Isso define a linha de base de cada município. Durante a apuração o modelo mede quanto cada município apurado se afasta dessa base e aplica esse desvio aos não apurados: a premissa pesa muito no início e quase nada depois de ~2–5% das seções.
